# 无人作证的晚祷三分钟Demo精确分镜

## 制作原则

- 目标游玩时长为 2 分 45 秒至 3 分 30 秒。
- 角色对白全部逐字摘自《第三章 第七次钟声》，只删节，不改写，不补写。
- “移动”“调查”“打断引导”等文字属于操作标签，不是角色对白。
- 跑图钟声由检查点触发，不使用会导致玩家漏剧情的真实倒计时。
- 主线没有失败结局；互动结果只影响记录完整度和界面反馈。

## 状态变量

| 变量 | 初始值 | 变化方式 | 用途 |
|---|---:|---|---|
| `bellStage` | 3 | 越过地图检查点 | 依次触发第四至第七声钟响 |
| `knifeChecked` | false | 调查厨房刀架 | 播放伊蕾娜与埃文的可选原文对白 |
| `hermannInterrupted` | false | 完成限时打断 | 记录“引导证词”异常 |
| `recordUsed` | false | 在病床前使用 B-17 病历 | 进入蓝灯证词段落 |
| `morseProgress` | 0 | 完成两组敲击 | 揭示 VIK 与 TOR |

## 逐秒分镜

### 镜头一 医务室起跑 00:00 至 00:20

**画面**：医务室近景。索菲位于左侧，伊蕾娜位于右侧，埃文处于后景。窗外暴雨，玻璃偶尔闪白。

**对白顺序**：

1. 索菲：“礼拜堂提前开始了。”
2. 伊蕾娜：“几点？”
3. 索菲：“七点十三。”
4. 伊蕾娜：“晚祷不是七点二十。”
5. 索菲：“今晚不是晚祷。是重演。”
6. 伊蕾娜：“他要重演炮击当夜的时间。”

**演出**：最后一句出现时，画面短暂压暗，目标条显示“在第七声钟响前抵达礼拜堂”。

**转场**：采用原文叙述“三个人从医务室侧门出去。”作为黑底字幕，随后进入跑图。

### 镜头二 后勤通道与厨房 00:20 至 00:47

**玩法**：玩家控制伊蕾娜，索菲和埃文自动跟随。WASD 移动，Shift 奔跑，E 调查。

**地图结构**：医务室侧门进入后勤走廊。主楼方向被封，玩家必须向厨房移动。

**检查点**：进入厨房触发第四声钟响。界面右上角由 `III` 变为 `IV`。

**可选调查 刀架**：玩家靠近刀架按 E，控制锁定并播放：

1. 伊蕾娜：“别紧张，中尉。我要是真想杀人，不会选厨房刀。”
2. 埃文：“那你会选什么？”
3. 伊蕾娜：“让别人以为自己正在执行正确命令。”

播放结束后恢复移动。没有调查时不补写任何替代对白。

### 镜头三 雨夜石廊 00:47 至 01:05

**检查点**：离开厨房触发第五声钟响。界面由 `IV` 变为 `V`，镜头短促震动。

**画面**：伊蕾娜停下扶住石墙，切换为半身立绘对话。

**对白顺序**：

1. 索菲：“您还好吗？”
2. 伊蕾娜：“钟声里有东西。”
3. 埃文：“什么东西？”
4. 伊蕾娜：“不是单纯钟声。下面叠了低频。”
5. 索菲：“留声机。”

**演出**：最后一句出现时加入极轻的唱针底噪。结束后恢复跑图，礼拜堂侧门出现交互光点。

### 镜头四 礼拜堂与第六声 01:05 至 01:28

**交互**：玩家在侧门按 E。

**转场**：画面切黑，第六声钟响。切换到礼拜堂视觉小说布局，钟声计数显示 `VI`。

**画面**：五张病床围成半圆，B-17 位于祭台附近，留声机在床边。赫尔曼站在中央，玛尔塔在祭台左侧。

**对白顺序**：

1. 赫尔曼：“少校。你比我预计得早了两分钟。”
2. 伊蕾娜：“这与你想要的不正好一致吗？”
3. 赫尔曼：“我想要的是可观察反应。自愿或非自愿，区别不大。”

**镜头**：第三句结束后，镜头缓慢推近 B-17，环境声音降低。

### 镜头五 第七次钟声 01:28 至 02:17

**触发**：镜头抵达 B-17 时，第七声钟响。计数由 `VI` 变成金色 `VII`。

**效果**：画面边缘轻微失焦、蜡烛摇晃、低频增强。提供“减弱震动”设置，不影响进程。

**对白顺序**：

1. 赫尔曼：“记录。第七次钟声后，B-17 出现反应。”
2. B-17：“……不要……”
3. B-17：“不要……让她……”
4. 赫尔曼：“不要让谁？”

**限时操作**：屏幕出现操作按钮“打断引导”。在计时结束前按下空格、E 或点击按钮。

**成功对白**：

1. 伊蕾娜：“赫尔曼。你在引导证词。”
2. 赫尔曼：“我在协助病人完成表达。”

**超时处理**：不增加新对白，直接进入下一镜头，并将 `hermannInterrupted` 保持为 false。

### 镜头六 病历证据与蓝灯 02:17 至 02:42

**交互**：证物栏自动亮起 B-17 病历。玩家点击病历或按数字键 1。

**对白顺序**：

1. 伊蕾娜：“我不是赫尔曼。我不会替你补全句子。”
2. 伊蕾娜：“如果你听得见，就回答我。第七声之后，发生了什么？”
3. 伊蕾娜：“你说，修道院没有旗。那你看见了什么？”
4. B-17：“灯……”
5. 伊蕾娜：“什么灯？”
6. B-17：“蓝……蓝灯……”
7. 伊蕾娜：“在哪里？”
8. B-17：“钟楼……窗……”

**演出**：蓝灯两字出现时，背景短暂闪过钟楼窗户的冷蓝色光。证据栏新增“蓝灯”。

### 镜头七 维克多身份揭露 02:42 至 03:10

**剪辑**：使用黑场和第七声余音完成删节，不添加说明性对白。B-17 抓住伊蕾娜的手。

**对白顺序**：

1. B-17：“少校……”
2. B-17：“地图……是我……”
3. 伊蕾娜：“你是谁？”

**摩斯交互**：玩家根据节奏点击六次。前三次解锁 `V I K`，后三次解锁 `T O R`。操作失败时允许重试，不重新播放对白。

**完成演出**：维克多停止抽搐，伊蕾娜切换为震惊表情。

4. 伊蕾娜：“维克多。”

**结尾**：画面停留三秒，只保留呼吸和雨声。淡出至“无人作证的晚祷 / 试玩结束”。

## 验收标准

- 可以从头到尾完成一次游玩，不出现无法继续的死锁。
- 跑图至少包含移动、奔跑、场景检查点和一个可选调查点。
- 第四至第七声钟响顺序固定且不会因移动速度被跳过。
- 所有角色对白与原剧本逐字一致。
- 未完成限时打断和摩斯输入时都有可恢复路径。
- 1280×720 及更大桌面浏览器可完整显示；窄屏显示触屏方向键。
