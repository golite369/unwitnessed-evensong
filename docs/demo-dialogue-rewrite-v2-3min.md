# 《无人作证的晚祷》三分钟 Demo 对话修改稿 V3（口语化修订）

> 仅修改对话文本，未写入 Demo。剧情事实、线索顺序和人物关系均以原剧本为准。

## 人物口吻

- **伊蕾娜**：先判断事实，再给结论；冷静、锋利，偶尔带一点军事化的黑色讽刺。
- **索菲**：紧张时会犹豫、解释或道歉；一旦涉及病人，语气会突然坚定。
- **埃文**：习惯用条例组织语言，以反问掩饰动摇；嘴上守程序，行动上仍保留底线。
- **赫尔曼**：礼貌、精确、从容，把伤害包装成“协助”“记录”和“可观察反应”。
- **B-17**：因重伤与失语保持碎裂短句；不强行写成长句，以免破坏人物状态。

## 场景一：医务室

索菲：少校，对不起。我知道你们不能继续留在这儿，可我必须告诉您——礼拜堂那边已经开始了，比原定时间早。赫尔曼也把 B-17 带过去了。

伊蕾娜：别急，慢慢说。现在几点？钟响到第几声了？

索菲：七点十三，刚响过第二声。晚祷明明七点二十才开始，可今晚根本不是晚祷。赫尔曼把病床围在祭台前，还把那台留声机搬到了钟楼下面……他是要重演那天晚上的事。

伊蕾娜：七点十三开始，一分钟一声，第七声就是七点十九。再过一分钟，正好是贝尔纳炮击开始的时间。他不是在等 B-17 自己开口，是想把人逼回那天晚上，再把逼出来的话当成证词。

埃文：护理员，我提醒你一句。你现在带她绕过警戒，不是在帮忙，是在协助受看押人员脱离监管。按条例，这件事够你上军事法庭了。

索菲：我知道。可今晚这份记录一旦写完，明天审判庭就会把它当成证词。到时候您信不信程序已经不重要了，所有人只会相信纸上写的东西。走侧廊吧，厨房后门通礼拜堂左边，正门有人守着。

【第三声钟响。三人从医务室侧门离开。】

## 场景二：厨房刀架（可选调查）

伊蕾娜：手别这么快，中尉。我要真想杀人，也不会在厨房里随手拿把刀。这里到处是脚印，墙上还会空一格，谁都知道刀是从哪儿拿的。

埃文：那您会怎么做？找一道没有署名的命令，再找个人替您把事情办了？

伊蕾娜：我会先让他相信，那道命令没有错。等他动了手，所有记录都会说，他只是在尽自己的职责。这样我不用碰武器，他也不会觉得自己杀了人。

## 场景三：雨夜石廊

索菲：少校，等等，您手在发抖。又头疼了吗？还是刚才那支药有问题？

伊蕾娜：别碰我。不是药，至少不全是。钟声下面还有别的声音，很低。钟停了，那声音还在，震得我后脑发麻。

埃文：还有别的声音？我只听见钟声和雨。您确定不是药效上来了？

索菲：留声机……赫尔曼让人在钟楼下面放了一台旧留声机，说是要记录钟声的回响。可机器接上以后，他就再也不许护理员靠近了。

伊蕾娜：那东西不是拿来记录的，是拿来播放的。他在用那种声音刺激伤员，逼他们想起炮击，再从说出来的话里挑出自己想要的答案。换个医学上的名字，就好像这件事没那么脏了。

## 场景四：礼拜堂

赫尔曼：少校，晚上好。你比我预想的早了两分钟。看来疼痛并没有影响你的判断。

埃文：医生，今晚的证词记录没有提前通知看守方。如果这是正式程序，请出示命令。如果不是，我有权要求你马上停止。

赫尔曼：中尉，你的职责是看守囚犯，可现在囚犯就站在礼拜堂里。你是在履行职责，还是在帮她违规，我想还是留到明早的报告里再解释吧。

伊蕾娜：你早就知道我会来。钟声响得整个修道院都听得见，侧廊却连一个守卫都没有。你不就是想看看，我听到这些以后会有什么反应吗？

赫尔曼：我只关心那些看得见、能重复、也能记下来的反应。它是自己出现的，还是被什么东西刺激出来的，对结果没有影响。

## 场景五：第七次钟声

赫尔曼：记录。七点十九分，第七次钟声后，B-17 出现反应。右手手指弯曲，呼吸加快，开始尝试说话。

B-17：……不要……

B-17：不要……让她……

赫尔曼：别急，慢慢说。你不想让谁知道？是站在你面前的伊蕾娜少校吗？

伊蕾娜：够了，赫尔曼。他只说了半句话，你就把想要的名字塞给他。别管这叫协助，你是在替他作证。

赫尔曼：他的语言能力已经严重受损。如果没人引导，他只能一直重复这些没有意义的声音，我们什么也问不出来。

伊蕾娜：那也该让他自己说。你把问题和答案都给了他，最后再删掉问题，只记下自己想听的那几个字。

## 场景六：病历与蓝灯

伊蕾娜：B-17，听我说。我不会替你回答，也不要你替任何人证明有罪。你只要告诉我，第七声之后，你自己看见了什么。

赫尔曼：少校，你不懂创伤访谈。再问下去，只会让他越来越混乱，也会让刚才的反应失去记录价值。

伊蕾娜：闭嘴。你已经替他说得够多了。B-17，病历上写着修道院没有旗。既然没有旗，你看见了什么？

B-17：灯……蓝……蓝灯……

伊蕾娜：蓝灯？那是塞利亚军在夜里标记医疗队的信号，炮兵不可能不认识。灯在哪儿？

B-17：钟楼……窗……

伊蕾娜：钟楼窗户里有蓝灯……那开火的人就知道这里是医疗点。可目标图上没有蓝灯。不是看错，是有人改过那张图。

## 场景七：身份揭露

B-17：少校……地图……是我……

伊蕾娜：别叫我少校。看着我，告诉我你是谁。说不出来，就敲给我听，一个字母也行。

索菲：别问了，他已经撑不住了。您非要他现在想起来，只会让他再经历一遍。

伊蕾娜：我得知道。不是为了审判，也不是为了给赫尔曼留下记录。我只想知道，我现在抓着的这只手，到底是谁的。

【B-17 在伊蕾娜掌心敲出旧式电报码：V、I、K、T、O、R。】

伊蕾娜：维克多……你还活着。可他们删掉了你的名字，让所有人都以为你已经死了。

## 校对说明

- 保留原剧本中的七点十三、七声钟、七点二十炮击、低频留声机、诱导证词、蓝灯、目标图与维克多身份等事实。
- 没有新增案件结论，也没有提前加入“伊甸”和地下室儿童支线，以免三分钟 Demo 信息过载。
- B-17 是唯一没有被改成长句的人物；他的碎裂语言是伤情、悬念与身份揭露的一部分。
- 本轮重点删除了过度工整的排比、书面化术语和作者式比喻，让对白更接近演员在紧张场景中会自然说出的句子。
- 正式内置时，应让开场从第二声钟开始，并在离开医务室时触发第三声，避免当前演示版本的钟声计数与原剧本时间线冲突。
