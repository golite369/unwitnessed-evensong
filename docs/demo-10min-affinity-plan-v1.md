# 《无人作证的晚祷》约 10 分钟 Demo 扩展与好感系统规划 V1

> 本文只做结构和系统规划，暂不改动游戏代码，不把新增对白直接写入 Demo。新增台词需先按现有剧本人物口吻单独审阅。

## 一、扩展目标

- 首次普通路线：约 **9 分 30 秒—10 分 30 秒**。
- 信息最完整的“伊甸”路线：约 **10 分 30 秒—11 分 30 秒**。
- 不用强制等待、重复走廊或长字幕凑时长。
- 新增一段可自由调查的跑图区域和一段结局前的短撤离。
- 关系页收录原剧本当前全部具名人物：索菲、埃文、维克多、赫尔曼、玛尔塔、安托，并为伊蕾娜保留玩家档案卡。
- 所有成年角色都进入可持续发展的关系系统；角色性别不作为进入情感路线的限制。安托只发展信任与保护关系。
- 玩家可以把关系保持在信任或战友情，也可以通过明确选择进入带有恋爱意味的“特别牵挂”。
- 好感影响人物是否主动帮忙、提供哪条私人线索、结尾由谁留下，而不直接替代推理、共情和控场。

## 三、新增可玩段落一：档案侧廊

### 触发位置

第五声钟后，三人抵达礼拜堂外。正门暂时被书记官和卫兵封住，玩家必须绕过一间被废弃的档案侧廊。

### 空间结构

```text
石廊入口
   ├─ 左侧药品柜：索菲擅长辨认
   ├─ 中央值勤桌：埃文擅长核对
   ├─ 右侧旧电话：伊蕾娜可独自调查
   └─ 礼拜堂侧门
```

玩家可以查看全部物件的表面信息，但第六声钟前只能深入调查其中一项。选择同伴并不锁死案件主线，只改变取得的证物、关系变化和后续说话权。

### 同行选择

#### A. “索菲，和我查药品柜。”

- 索菲好感上升。
- 取得“阿洛芬换药登记”。
- 后续索菲可以证明 B-17 的用药时间被赫尔曼改过。
- 若此前曾优先询问病人或关闭刺激，解锁一句更私人的担忧，但不立刻进入恋爱状态。

#### B. “埃文，值勤记录交给你。”

- 埃文好感上升。
- 取得“礼拜堂临时警戒令”。
- 后续埃文可以指出命令编号与帝国军医部格式不符。
- 若此前尊重过记录程序，埃文会主动把原件而不是抄件交给伊蕾娜。

#### C. “你们守门，我去接旧电话。”

- 不增加索菲或埃文好感。
- 推理增加，取得一段不完整的炮兵值班录音。
- 听见年轻维克多曾使用的短码，维克多关系记忆上升。
- 风险是 B-17 稳定度不获得额外保护。

### 跑图与交互

- 区域长度约为现有后勤通道的三分之一。
- 三个物件均有近距离交互提示，不允许隔空点击触发。
- 深入调查后第六声钟响起，未选择的两项只保留“来不及继续”的表面记录。
- 退出侧廊时，同伴在实际跑图中跟随；被选择的同伴距离伊蕾娜更近，另一人略微落后，作为无文字关系反馈。

## 四、新增可玩段落二：停电撤离

### 触发位置

玩家取得本轮核心答案后，礼拜堂因低频设备过载短暂停电。赫尔曼命令卫兵封锁记录席，索菲需要转移 B-17，埃文需要保住证物。

### 玩法目标

- 约 35—45 秒的短跑图，不重走来时道路。
- 伊蕾娜从祭台穿过侧门到圣器室。
- 玩家需要在“扶住 B-17”“带走证物”“拖住卫兵”三件事中亲自承担一件，并把另外两件托付给同伴。
- 选择影响关系和结尾补充线索，不设置失败即死亡。

### 三种行动

#### A. 亲自扶住 B-17

- 维克多好感明显上升，B-17 稳定度上升。
- 索菲负责药品与撤离路线。
- 埃文必须决定是否替伊蕾娜保住军令；需要一定埃文好感或控场，否则只带走抄件。

#### B. 帮索菲转移病床与药品

- 索菲好感明显上升。
- 她会在圣器室交出被她私自保留的换药标签。
- 维克多关系不下降，但无法在本轮得到完整掌心短码。

#### C. 与埃文守住记录席

- 埃文好感明显上升。
- 能保留有法律价值的原始笔录。
- 如果此前对病人过于强硬，索菲会明确表示不满；这是关系后果，不直接判定案件失败。

## 五、好感系统

### 完整人物名单

| 角色 | 关系核心 | 喜欢的行动 | 反感的行动 | 高好感提供 |
|---|---|---|---|---|
| 索菲 | 保护病人、共同承担风险 | 先确认伤员状态、尊重护理判断、帮她撤离 | 把病人纯粹当证物、命令她独自担责 | 换药标签、主动关闭刺激、圣器室私下场景 |
| 埃文 | 程序底线、在命令之外作选择 | 让证词逐字记录、把证物托付给他、承认他的风险 | 利用军衔压迫、强夺钥匙后否认责任 | 原始笔录、延迟上报、守则之外的私下场景 |
| 维克多 | 被当作一个人、共同记忆 | 非诱导提问、停止刺激、回应旧短码 | 强迫回忆、把身份当成破案工具 | 灰线短码、身份记忆、掌心回应场景 |
| 赫尔曼 | 危险关注、智性对抗、控制欲 | 看穿他的诱导仍愿意正面交锋、承认医学判断中真实的部分 | 把他简单当成失控疯子、回避他的核心问题 | 未删节观察记录、第二台留声机线索、危险对谈 |
| 玛尔塔 | 告解、责任与赦免边界 | 允许她完整说明地下室决定、追问事实但不替她开脱 | 用索菲妹妹的死亡逼她立刻认罪、把信仰当成笑话 | 无来源电报、修道院平面图、“白鸽”救援线路 |
| 安托 | 安全感、保护与非语言信任 | 蹲下平视、归还纽扣、不过度追问 | 抢夺物件、利用恐惧让他带路 | 黄铜纽扣、钟楼目击位置、隐藏通道提示 |

伊蕾娜不设置自己的好感值。她在页面顶部拥有独立玩家档案卡，记录本轮主要态度、已经承担的责任和当前最亲近的人物。

赫尔曼与玛尔塔都纳入关系系统，但不把“好感提高”等同于原谅或道德认可：

- 赫尔曼的正向变化表现为兴趣、尊重和把伊蕾娜视作对等对手；同时保留“危险”“控制”“利用”等状态标签。当前 Demo 最多发展到危险的私人关注，后续章节才允许玩家决定是否继续发展情感。
- 玛尔塔的正向变化表现为愿意告解、交出教会资料和停止隐瞒。达到高阶段后可以出现带有亲密可能性的情绪回应，但她的修女身份和炮击责任不会因为好感而被抹去。
- 安托是儿童角色，只能发展保护、信任和监护式羁绊，永远不出现恋爱或暧昧选项。

### 内部数值与玩家呈现

- 六名具名 NPC 均保存关系数据。内部值建议为 `-2—6`，初始均为 `0`。
- 页面不显示“+1”“+2”或爱心数量，只显示关系阶段。
- 索菲、埃文、维克多、玛尔塔使用：**戒备 → 关注 → 信任 → 亲近 → 特别牵挂**。
- 赫尔曼使用专属阶段：**观察 → 兴趣 → 重视 → 执着 → 危险共鸣**。
- 安托使用专属阶段：**躲避 → 观察 → 接近 → 信任 → 安心**。
- 普通选择通常变化 1 点；关键托付和保护行为变化 2 点。
- 明显违背角色底线时才降低 1 点，避免玩家因为一次普通选择永久错过关系线。
- 推理、共情、控场仍决定案件调查方式；好感只决定人物是否愿意把额外信息和私人情绪交给伊蕾娜。

### 全性向规则

- 伊蕾娜可以与所有成年可发展角色进入情感路线，不设置性别或职业身份限制。
- 不在开场询问玩家“性取向”，也不根据选择过的角色性别推断玩家偏好。
- 达到“亲近”后，结尾出现一次明确选择：保持深度战友/同伴关系，或表达“特别牵挂”。
- 恋爱选项必须由玩家主动选择；高好感不会自动把普通关心解释成恋爱。
- 多名角色同时达到条件时，玩家在结尾选择本轮回应谁；其他角色保留已建立的信任，不因未被选择而突然降为敌对。
- 赫尔曼在本章只能解锁“继续危险关系”的选择，不能在医患、拘押和证词操控仍然存在时直接进入浪漫结局。
- 安托不适用全性向恋爱规则，只保留非浪漫信任线。

## 六、好感页面设计

### 入口

- 暂停菜单增加“关系”按钮，位置放在“背包”下方。
- 跑图时可按 `R` 打开；对话、回忆、限时选择期间禁止打开。
- 标题封面的“继续游戏”只负责读取最近存档，不直接打开关系页。

### 页面布局

```text
┌──────────────────────────────────────────────────────────┐
│ RELATIONSHIP / 人物关系                              ×   │
├──────────────┬──────────────┬──────────────┬─────────────┤
│ 伊蕾娜档案：本轮态度、责任记录、当前牵挂              │
├──────────────┬──────────────┬──────────────┬─────────────┤
│   索菲       │   埃文       │ B-17/维克多  │  当前详情   │
│   赫尔曼     │  玛尔塔修女  │   安托       │ 关系记忆    │
├──────────────┴──────────────┴──────────────┤ 关键选择    │
│ 不显示数值；角色使用不同关系阶段和纹样                  │ 可解锁场景  │
└───────────────────────────────────────────┴─────────────┘
```

### 卡片信息

每张卡只显示：

1. 角色姓名与当前关系阶段。
2. 一句会随选择变化的“最近印象”，例如“她至少先问了病人的情况”。
3. 两到三条已经发生的关系记忆，不展示尚未触发事件的具体条件。
4. 达到“亲近”后显示“有些话可以在安全的时候说”，不直接显示“恋爱路线已解锁”。

### 视觉规则

- 沿用当前黑金菜单和透明对话框，不使用粉色爱心或现代手机式列表。
- 索菲用灰白织物纹样，埃文用暗铜军章纹样，维克多用灰线短码纹样区分卡片。
- 赫尔曼使用白瓷、怀表与病历红线；玛尔塔使用黑色念珠与旧教会纹样；安托使用缺眼布熊和黄铜纽扣纹样。
- 未认出 B-17 前，维克多卡片显示为“B-17 / 身份不明”；完成身份揭露后发生翻牌式转场。
- 好感发生变化时不弹数字，只让对应角色卡边框短暂亮起，并在下一次打开关系页时新增一条关系记忆。

## 八、完整人物关系收束

### 索菲：共同承担

条件：索菲达到“亲近”，且玩家至少一次优先保护病人。

- 圣器室中索菲承认，她早就藏下了一枚被更换的药瓶标签。
- 她不是因为相信伊蕾娜无罪才帮忙，而是因为不愿再让患者成为任何一方的工具。
- 玩家可以选择“等审判结束后，再把剩下的话告诉我”进入含蓄情感走向，或选择“把标签交给埃文，我们先保住病人”保持深度同伴关系。

### 埃文：守则之外

条件：埃文达到“亲近”，且原始笔录被保留。

- 埃文决定延迟七分钟上报伊蕾娜离开看押区域，为证物转移留下时间。
- 他会明确说这不是相信她，而是拒绝让程序只保护写下命令的人。
- 玩家可以选择把未上锁的手铐交回他掌心，进入含蓄情感走向；也可以要求他以证人身份站到审判庭上，保持战友关系。

### 维克多：归来者

条件：维克多达到“亲近”，完成电报码且没有强迫他继续回忆。

- 维克多在掌心补完一段只属于两人的旧短码，指出“灰线”仍有第二份副本。
- 本段不进行突然告白；他的创伤和失语状态决定关系只能停在明确的牵挂与等待。
- 玩家可以选择回应旧短码，进入未来可发展的情感走向；也可以选择握住他的手但不追问，保持深度羁绊。

### 赫尔曼：危险观察

条件：赫尔曼达到“重视”，玩家至少两次拆解了他的证词逻辑，同时没有把所有医学观察一概否定。

- 赫尔曼会交出一页未删节的观察记录，但要求伊蕾娜承认自己刚才同样利用了维克多的记忆。
- 玩家可以选择继续这场私人对谈，使关系进入“危险共鸣”；也可以只收下记录，明确拒绝他的控制。
- 本章不出现直接告白或亲密接触。该选择只决定后续是否开放成年人之间的复杂情感路线，不把操控包装成已经成立的爱情。

### 玛尔塔：告解之外

条件：玛尔塔达到“亲近”，玩家取得地下室或白鸽线索，并允许她完整说明撤离决定。

- 玛尔塔交出修道院旧平面图和无来源电报，承认自己隐瞒了地下室收容者与索菲妹妹的结局。
- 玩家可以选择告诉她“我不会替你赦免，但我会听完”，开启未来情感路线；也可以要求她首先向索菲和幸存者作证，保持深度盟友关系。
- 她的宗教身份成为关系冲突的一部分，而不是禁止玩家选择她的理由。

### 安托：被保护的目击者

条件：安托达到“信任”，玩家没有抢夺纽扣或强迫他带路。

- 安托用布熊和手势指出自己曾在钟楼看见维克多，并标出一条不会经过卫兵的旧通道。
- 该线只提供非浪漫的保护与信任收束。伊蕾娜可以承诺把他带离审讯区域，不能出现任何暧昧选项。

## 九、案件答案与好感的边界

- 低好感不能让已经取得的核心证据凭空消失。
- 高好感提供的是证物原件、未公开动机、私人记忆或行动协助，不直接宣布伊蕾娜无罪。
- 三条普通案件路线仍回答“蓝灯”“不是她”“维克多”；完整路线仍回答“伊甸”。赫尔曼、玛尔塔和安托的关系内容补充证据来源，不替换核心答案。
- 关系结尾写入独立的“人物记录”，不覆盖“案件记录”。
- 玩家可以得到完整案件答案但没有恋爱结尾，也可以获得高好感但因调查选择不同只得到部分案件答案。

## 十、存档与周目规则

- “继续游戏”恢复到最近一个稳定节点，不恢复到限时选择倒计时中间。
