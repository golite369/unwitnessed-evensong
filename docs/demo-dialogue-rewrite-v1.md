# 无人作证的晚祷三分钟 Demo 对话修改稿第一版

## 人物声音定位

- 伊蕾娜：先判断事实，再给结论。语气冷静、短促而有压迫感，偶尔使用军事经验形成的黑色讽刺，不轻易暴露情绪。
- 索菲：说话有犹豫、停顿和补充，紧张时会先道歉或解释，但涉及病人时会突然坚定。
- 埃文：习惯以条例和职责组织语言，常用反问掩饰不安；嘴上保持怀疑，行动却比立场更诚实。
- 赫尔曼：礼貌、完整、精确，避免使用带道德判断的词，把伤害包装成记录、协助和可观察反应。
- B-17：保留失语和重伤造成的碎裂表达，不强行长句；信息量通过断续词组逐步恢复。

## 场景一 医务室

索菲：少校，抱歉，我知道你们不能继续留在这里，可我还是得来告诉您——礼拜堂提前开始了，赫尔曼已经把 B-17 带过去了。

伊蕾娜：先把气喘匀了再说，索菲。现在几点，钟又响过几次？

索菲：七点十三，刚才是第三声。晚祷明明还有七分钟，可所有军医和书记官都已经进了礼拜堂，像是在等一个早就定好的时刻。

伊蕾娜：晚祷定在七点二十，从不为某个病人提前；赫尔曼偏偏选七点十三开始敲钟，那就不是临时起意，也不是宗教仪式。

索菲：是……今晚根本不是晚祷。他让人把病床围在祭台前，还把那台留声机搬到了钟楼下面；他想让那些伤员重新经历炮击发生前的几分钟。

伊蕾娜：七点十三起钟，每隔一分钟一声，第七声落在七点十九；再过一分钟，就是炮击记录里的开火时间。明白了吗？他不是在等待证词，他要重演那一夜，把证词制造出来。

索菲：走侧廊吧，厨房后门能到礼拜堂左侧。正门有士兵，我不确定他们还会不会听我的，但侧廊至少还没有人看守。

埃文：护理员，你最好清楚自己在做什么。按照条例，这已经不是带路，而是在协助一名被看押人员绕开警戒。

索菲：中尉，如果今晚的记录完成，明天审判庭就会把它叫作证词；到那个时候，他们不需要您相信程序，因为程序会替所有人相信赫尔曼。

## 场景二 厨房刀架可选对话

伊蕾娜：别那么快摸枪，中尉。我要是真想杀人，不会在一间满是脚印和指纹的厨房里，挑一把谁都数得清、谁都认得出的刀。

埃文：是吗？那少校会选什么——一条没有署名的命令，还是一个事后可以被写成擅自行动的替罪羊？

伊蕾娜：我会让一个人确信自己正在执行正确命令，等他动手以后，再让每一份记录都证明他只是尽了职责；这样既不用沾血，也不会缺少证人。

埃文：好吧，至少这次您肯诚实地告诉我，为什么一纸命令有时比刀更危险。

## 场景三 雨夜石廊

索菲：少校，您脸色很差，先别再往前走了；您的手在发抖，是头痛又发作了吗？

伊蕾娜：先别碰我。不是药，也不只是头痛——钟声里面还压着另一层声音，它太低了，听不清，却一直在往人的骨头里钻。

埃文：另一层声音？说实话，我只听见一口旧钟和一场快把屋顶掀掉的雨；您确定不是那支药剂在起作用？

伊蕾娜：我分得清药物和震动，中尉。钟声落下以后，低频还在继续，而且节奏没有跟着余音衰减；有人把另一段声音叠在钟声下面，故意让我们以为那只是共鸣。

索菲：留声机……赫尔曼让人在钟楼下放了一台旧式留声机，说是要记录钟声通过石墙时的共鸣；可那台机器接上以后，他从来不许护理员靠近。

伊蕾娜：那就不是记录，而是播放。他在用我们听不清的声音刺激伤员，把他们推回炮击发生以前，再把创伤反应写成自愿证词。

埃文：如果这是真的，那么今晚礼拜堂里的记录从第一行开始就是伪证；可我们现在进去，也等于亲手承认自己绕开了看守条例。

伊蕾娜：那就把两件事都记清楚。你可以在报告里写我违规，但别让赫尔曼把一场实验写成审判。

## 场景四 礼拜堂

赫尔曼：少校，晚上好。你比我预计得早了两分钟——看来疼痛并没有削弱你的判断，反而让你比大多数守时的人更敏锐。

埃文：医生，按照看押条例，今晚的证词记录没有提前通知军事看守方；如果这是正式程序，请出示命令，如果不是，我有权要求你立刻停止。

赫尔曼：中尉，你的职责是看守囚犯，而现在囚犯完整地站在礼拜堂里；至于你是在履行职责，还是参与她的违规行动，我建议留给明早的书面报告判断。

伊蕾娜：你明知道我会来，却故意把门口留给两个士兵，把侧廊留空；这与你想要的不正好一致吗——多一个未经邀请、却足够熟悉炮击当夜的人，供你观察反应。

赫尔曼：我想要的只是可观察、可重复、能够被记录的反应。至于它来自自愿回忆、条件刺激，还是某位少校擅自闯入造成的压力，对结果而言区别并不大。

伊蕾娜：当然，对你而言，人只要还能产生结果，就不必继续被当作一个人。

赫尔曼：请不要急着赋予方法道德含义，少校；战争已经制造了伤口，我只是让伤口提供仍然保存的信息。

## 场景五 第七次钟声

赫尔曼：记录时间，七点十九分；第七次钟声后，B-17 出现明确运动反应，右手指屈曲，呼吸频率上升，并开始尝试发声。

B-17：……不要……钟……不要再响……

赫尔曼：别急，你不必说完整，只需要顺着记忆继续。你想让谁停下，还是不想让谁知道？

B-17：不要……让她……看见……地图……

赫尔曼：很好，你已经听见她了。告诉我，不要让谁看见，又是谁改过那张地图？

伊蕾娜：够了，赫尔曼。你先给他一半句子，再把你需要的答案放在后面；这不是提问，是把一个失去抵抗能力的人推向你预先写好的证词。

赫尔曼：我只是在协助病人完成表达。语言能力受损的人需要明确的路径，否则有价值的信息会永远困在无意义的音节里。

伊蕾娜：不，你是在替他决定哪些音节有价值；等他终于说出你要的词，你就会删掉问题，只留下答案。

赫尔曼：那么请你示范吧，少校。既然你相信自己比医学记录更接近真相，就让我们看看他会不会选择你的问题。

## 场景六 病历与蓝灯

伊蕾娜：B-17，听清楚，我不是赫尔曼，也不会替你补全任何一句话。你不必证明谁是无辜的，只要告诉我，你自己究竟看见了什么。

伊蕾娜：如果你还能听见，就从第七声以后开始回答；不要顺着我的词，也不要顺着他的词——第七声落下以后，真正发生了什么？

赫尔曼：少校，你没有接受过创伤访谈训练；继续施压只会扩大病人的混乱，并污染已经出现的有效反应。

伊蕾娜：闭嘴。你已经替他说得够多了，现在轮到他决定什么叫作有效。

伊蕾娜：病历里写着，你反复说修道院没有旗；既然没有旗，你凭什么认出目标，又究竟在钟楼上看见了什么？

B-17：不是旗……窗……钟楼的窗……有灯……

伊蕾娜：什么颜色的灯？它亮了多久，是一直亮着，还是在开火以前才出现？

B-17：蓝……蓝灯……第七声以后……亮了一次……

伊蕾娜：蓝灯亮起以后呢？谁把它当成信号，谁下令开火？

B-17：命令……被改了……地图也……不是原来的地图……

索菲：仪器读数还在升，别再碰他，让他自己把话说完；他不是你们记录板上的一个反应。

## 场景七 身份揭露

B-17：少校……我没能……把地图送出去……

伊蕾娜：别再叫我军衔。看着我，告诉我你是谁；只要是你自己的答案，一个字也够。

B-17：地图……是我……我改的……可蓝灯……不是我……

索菲：别问了，他已经撑不住了；您想知道的名字，也许只会让他再死一次。

伊蕾娜：我必须知道。不是为了审判，也不是为了赫尔曼的记录——是为了确定我现在握着的，到底是谁的手。

B-17：V……I……K……

伊蕾娜：维克……

B-17：T……O……R……

伊蕾娜：维克多。原来你没有死，你只是被他们从名字里删掉了。

## 审稿说明

- 本稿保留了原剧情的时间、钟声、留声机、诱导证词、蓝灯、地图与维克多身份等关键事实。
- 新增内容主要来自原剧本同一场景里已经存在、但三分钟版本此前删掉的信息，没有改变案件结论。
- B-17 的句子刻意不写成长段；他的语言从单词逐步恢复到短句，本身就是身份揭露的一部分。
- 这版对白尚未写入 `game.js`，用于先确认人物声音与信息密度。
