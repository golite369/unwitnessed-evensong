# 《无人作证的晚祷》可玩 Demo

第三章“第七次钟声”的浏览器试玩版本，当前包含：

- 使用原版主视觉制作的完整 16:9 雪夜入场封面；图中的开始、继续、存档、设置和退出均有对应交互。
- 关键调查节点自动保存，“继续游戏”可恢复最近一次进度。
- 约 6—8 分钟的剧情、跑图和调查流程。
- 炮击冷开场，以及分散在医务室、厨房、石廊和礼拜堂的回忆片段。
- 五次会改变推理、共情、控场、B-17 稳定度和证物的选择。
- “蓝灯”“维克多”“不是她”“伊甸”四条调查结果路线。
- WASD/方向键移动、Shift 跑步、E 调查。
- 菜单、调查状态、案件记录和证物背包。
- 第七声限时决定与维克多电报码互动。

## 运行方式

直接双击打开 `index.html` 即可开始。

如果浏览器限制了本地脚本，也可以在这个目录下用任意静态服务器打开。

推荐在仓库根目录运行：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8765/`。此地址是本地试玩地址，不是公网部署地址。

## 当前制作状态

已实现版本约 6—8 分钟。约 10 分钟扩展和完整人物好感系统目前为设计规划，尚未内置到游戏。

游戏在当前浏览器自动保存调查节点，换设备或清除浏览器数据后不会保留进度。

## 分支解锁原则

- 推理达到要求：追查蓝灯与目标图。
- 共情达到要求：关闭刺激并确认 B-17 身份。
- 控场达到要求：扣押军令并保留正式记录。
- 推理、共情、证物和 B-17 稳定度同时满足：进入“伊甸”完整路线。

属性数值不会显示在跑图 HUD 或结尾，只能在暂停菜单的“调查状态”中查看。

## 主要文件

- `index.html`：游戏界面结构。
- `style.css`：黑金 UI、回忆演出和分支界面。
- `game.js`：跑图、对话、属性、证物和分支逻辑。
- `docs/demo-5min-branch-design-v1.md`：分支设计。
- `docs/demo-flashback-storyboard-v1.md`：回忆精确分镜。
- `assets/generated/flashbacks/`：回忆场景、年轻维克多与军令资产。
- `source-assets/`：用户提供的原始图片、GIF 效果参考和第三章剧本。
- `scripts/`：精灵图规范化、透明背景处理和剧本文本提取辅助工具。

汇报 PPT 和宣传 MP4 不包含在本仓库。原始文件继续保存在本地项目资料目录。
