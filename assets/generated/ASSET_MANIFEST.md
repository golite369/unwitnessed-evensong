# 《无人作证的晚祷》Demo 生成资产清单

生成方式：Codex 内置 ImageGen。所有文件均为新增文件，未覆盖用户原始资产。

## 统一风格锁定

- 半写实手绘二维视觉小说风格，细腻线稿与克制的绘画式明暗。
- 冷灰、灰绿、炭黑为主色，旧金只用于徽章、证物与界面强调。
- 虚构的战时欧洲修道院世界，不使用现实政治组织标志。
- 角色严格参照原三视图；透明立绘保留完整头部、手部和道具。
- 场景采用横屏视觉小说构图，预留左右角色站位，不烘焙文字或界面。
- UI沿用黑底、旧金双线、对称哥特花纹，所有文字由程序动态呈现。
